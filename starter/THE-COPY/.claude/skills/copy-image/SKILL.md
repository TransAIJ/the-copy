# THE・COPY 画像と画面（i2i）

全体の流れ（0〜7段）・コピー盤・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには画像と画面の部品だけを書きます。

i2i は2種類に分けます。

| 種類 | 例 | 作り方 |
|---|---|---|
| 配置（文字と枠が主役） | LP・スライド・アプリの画面・文字の多いインスタの画像・図解・バナー | HTML と CSS で作り、同じ幅で撮る（Claude だけでできる） |
| 写真の層（絵が主役） | 写真・イラスト・サムネの人物や背景 | 画像のモデルが要る（下の「写真の作り方」） |

1つの画像に両方がある時（写真の上に文字が乗ったサムネなど）は、部品を「写真の層 i2i」と「文字の層 i2i」に分け、文字は HTML で重ねます。画像のモデルに日本語の文字を書かせると崩れるためです。

## Step 1: 見る

### 配置（LP・画面・文字の画像）

- スマホ 390px とパソコン 1440px の両方で、上から下まで区画ごとに見ます
- 作業フォルダで Node.js がある時は、測る台本で文字の計算値まで取ります

```bash
npx -y playwright@1 install chromium   # 初回だけ（数分）
node scripts/measure_page.mjs <URL> --out 素材棚/元の物/<名前>
```

  1画面ずつの画面写真（`sp-01.png`…・`pc-01.png`…）と、見出し・本文・ボタンの書体・太さ・大きさ・行間・色・下地の色・余白を `measure.json` に書きます
- 台本を使えない時（チャット・Node.js が無い）は、使う人からスマホとパソコンの画面写真をもらい、Claude が画像を見て測ります（文字の大きさは、画面の幅との比で px に直します）
- ログインの要るページは開きに行きません。使う人の画面写真で見ます

### 写真・イラスト

要素ごとに次の10項目を書きます: ①写っている範囲（全身・上半身・手元）②顔の出し方 ③姿勢 ④カメラの距離と角度 ⑤主役（顔・手元・商品・小物）⑥見た人の気持ちを動かす芯 ⑦小物 ⑧服 ⑨背景 ⑩AI っぽく崩れやすい所（手指・目・文字）

## Step 3: ①の値

| 部品 | ①に書く値 |
|---|---|
| 区画の順番 | ファーストビュー → 問題 → … → CTA。各区画の高さ（スマホで何画面分か） |
| 文字 | 見出し・本文・注記・ボタンの書体の種類（明朝・ゴシック・丸）・太さ・大きさ px・行間・字間 |
| 色 | 地・本文・強調の3役と、その明るさの差。色そのものは自分のブランドの色に替える |
| 余白と列 | 区画の上下の余白 px、左右の余白、列の数と幅、画像と文字の比 |
| CTA | ボタンの数・位置・大きさ・色の役・文言の字数 |
| 写真 | 上の10項目の値（例: 斜め上45度・手元が画面の60%・背景はぼかす） |

**写さない物**: 元の画像・文章・ロゴ・イラスト・人物・商標。書体・大きさ・太さ・行間・余白・列の幅・区画の順番と配置は、値で写してよい物です。

## Step 6: 作る

### 配置（HTML で作って撮る）

1. 型の①の値をそのまま CSS の値にします（`font-size`・`font-weight`・`line-height`・`letter-spacing`・`padding`・`max-width`）
2. 中身は②（自分の文章・自分の写真・自分の実績）だけで埋めます。画像が無い所は、灰色の枠に「（ここに〇〇の写真）」と書いて残します
3. スマホ 390px とパソコン 1440px で撮り、元の画面写真と同じ大きさで横に並べます。作業フォルダなら `node scripts/measure_page.mjs file:///…/できた物.html --out できた物/<名前>/measure` で同じ値を測って比べます
4. インスタの画像やバナーのように1枚の画像にする物は、その縦横比の HTML（例: 1080×1350）を作って撮ります

### 写真の作り方（使う人が選ぶ。既定は「手で貼る」）

詳しくは `references/photo-routes.md` です。

| 方法 | 使う人の手間と費用 |
|---|---|
| 1. 手で貼る（既定） | THE・COPY が「元の画像」と「写す所・替える所を書いた短い指示」を出し、使う人が ChatGPT か Gemini のアプリに元の画像と一緒に貼る。導入は0分 |
| 2. Codex で自動（作業フォルダ） | 使う人の ChatGPT のログインで動く Codex の画像生成を呼ぶ。Codex の導入とログインが要る |
| 3. 使う人の API キー（作業フォルダ） | `scripts/image_api.py` で OpenAI か Gemini の画像の API を呼ぶ。1枚ごとに使う人が払う。キーが無ければ動かない |

守ること: 元の写真の人物・顔・ロゴ・文字を出力に残さない。実在の人に見える画像を作らない。モデルの安全判定で止められた物を言い換えて通さない。

## Step 7: 比べる

- 元と作った物を、同じ幅・同じ区画で横に並べた画像を作ります（作業フォルダでは `できた物/<名前>/compare.png`）。並べた画像に付ける見出しの文字は、HTML に2枚を並べて撮って入れます。Python の画像の部品（PIL）の既定の書体では、日本語が四角になります
- 区画ごとに ①の値が合っているか（文字の px・太さ・行間・余白・順番）を表にします
- 写しすぎ: 元の画像・文章・ロゴが残っていないか。構図だけでなく服・小物・背景まで同じになっていないか
- 写せていない: 区画の順だけ似て、文字の大きさや余白が自分の元の癖のままになっていないか
