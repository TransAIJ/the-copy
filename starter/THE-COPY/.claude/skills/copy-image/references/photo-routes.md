# 写真の作り方（i2i の写真の層）

Claude は写真の画像を作りません。写真の層は、使う人が持っている画像のモデルで作ります。どの方法でも、THE・COPY が出すのは同じ「指示の紙」です。

## 指示の紙（どの方法でも同じ）

```
元の画像: <ファイル名>（このあと一緒に渡す）
写す所: <売れている理由と、10項目のうち構図・主役・カメラの距離と角度・気持ちを動かす芯。例: 作業の途中の手元が主役で、本当にやっている人だと分かる。斜め上から撮る。背景はぼかしたカフェ。自然光で暖色>
替える所: <②。例: 手に持つ物を自分の商品（白いノート）にする。人は写さず手だけ>
残さない物: 元の画像の人物・顔・ロゴ・文字・商品
縦横比: <例: 4:5（1080×1350）>
文字: 入れない（文字はあとで HTML で重ねる）
```

- 指示は短くします。長い説明より、元の画像を見せる方が効きます
- 実在の人に見える顔・有名人・他社のキャラクターを作りません。モデルが断った物を言い換えて通しません
- できた画像は、元の画像と横に並べて「写しすぎ」（構図だけでなく服・小物・背景まで同じ）を見ます

## 1. 手で貼る（既定・導入0分）

1. THE・COPY が「指示の紙」と元の画像を出します
2. 使う人が ChatGPT か Gemini のアプリを開き、元の画像を添付して、指示の紙を貼ります
3. できた画像を THE・COPY（チャットか作業フォルダの `素材棚/自分の素材/`）に戻します
4. THE・COPY が文字の層を HTML で重ね、元と並べて比べます

無料の枠で何枚作れるかは、各アプリの決まりによります。

## 2. Codex で自動（作業フォルダ・使う人の ChatGPT のログイン）

使う人が Codex の CLI を入れて自分の ChatGPT でログインしている時だけ使えます。API キーは要りません（使う人の ChatGPT の枠を使います）。

```bash
codex exec --skip-git-repo-check "まず view_image で 素材棚/元の物/<元>.jpg を見てください。次に image_gen で、次の指示の紙どおりの画像を1枚作り、できた物/<名前>/photo.png に保存してください。<指示の紙>"
```

- 先に `view_image` で元の画像を見せてから `image_gen` で作らせます。`-i` で画像を渡しただけでは、元を見て作ったことになりません
- 画像は文章より多く枠を使います

## 3. 使う人の API キー（作業フォルダ・従量）

使う人が自分で作った OpenAI か Gemini の API キーを、作業フォルダの `.env` に入れた時だけ動きます。1枚ごとに使う人が払います。THE・COPY の作者は鍵を受け取りません。

```bash
# .env（git に入れない。チャットに貼らない）
OPENAI_API_KEY=...        # どちらか一方でよい
GEMINI_API_KEY=...

python3 scripts/image_api.py --provider openai --image 素材棚/元の物/<元>.jpg --prompt-file 指示の紙.txt --out できた物/<名前>/photo.png
python3 scripts/image_api.py --provider gemini --image 素材棚/元の物/<元>.jpg --prompt-file 指示の紙.txt --out できた物/<名前>/photo.png
# 送る前に中身だけ確かめる（送らない・鍵を使わない）
python3 scripts/image_api.py --provider openai --image ... --prompt-file ... --out ... --dry-run
```

- 鍵は環境変数か `.env` からだけ読みます。画面に出さず、ファイルに書き出しません
- 料金は各社の料金表のとおりです。使う前に料金表を見てください
