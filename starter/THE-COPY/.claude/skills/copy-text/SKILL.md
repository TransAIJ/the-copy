# THE・COPY 文章（t2t）

全体の流れ（ステップ0〜7）・ダッシュボード・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには文章のパーツだけを書きます。

## Step 1: 全文を1文ずつ見る

- 元の本文を `素材/お手本/<名前>.txt` に保存します（チャットでは会話の中に置きます）。X の投稿は、使う人が本文を貼るかスクショを渡します。取りに行きません
- 前後の文脈も見ます: 投稿なら前後の投稿・プロフィール・添付画像の有無、記事なら題名と見出しの並び、メールなら件名
- `python3 scripts/text_stats.py <元.txt>` で、全体の量（文字数・段落・箇条・数字を含む文の数）を数えます。情報量を見るためです。1文の字数や語尾の割合も出ますが、型には真似しません。Python が無い時は、同じ項目を Claude が数えます

## Step 2〜3: 売れている理由と①真似するもの

用途ごとのパーツの雛形は the-copy の `references/uses.md` にあります。文章では次の項目を必ず見て、①にします。

| 見る項目 | ①に書くものの例 |
|---|---|
| 売れている理由 | パーツごとに1行。読み手が何をするかで書く（例: 自分の失敗の場面を思い出して止まる／原因が分かって安心する／手順の数が分かって試したくなる） |
| 冒頭 | 入り方の種類（場面・数字・言い切り・問いかけ・会話文）と、2文目で何をするか |
| 読み手 | 誰に向けているか（はじめての人・比べている人・もう使っている人） |
| 痛み | 表の悩みと本音を分けて1行ずつ |
| 欲求 | 売上・承認・楽さ・安心・優越感のどれを刺しているか |
| 構造 | 問題 → 原因 → 反転 → 解決 → 行動 のような順番と、各段の役割 |
| 中身 | 扱っている話題と論点を箇条で。論点は真似し、例・根拠・数字は自分のものにする |
| 情報量 | 箇条・手順・事例・証拠・FAQ の数 |
| 証拠 | 実績・数字・具体の場面・失敗・比べ・スクショの、どれを何個どこに置くか |
| CTA | どこで・何をさせるか。CTA の前の押しが何をしているか |

真似するもの: 売れている理由／冒頭の入り方の種類／読み手を自分のことだと思わせるやり方／話の順番／論点／箇条・手順・事例の数／反論への答えの順番／証拠の出し方／CTA の前の押し方

真似しないもの: 1文の字数・1行の字数・語尾の割合の値（文の長さと語尾は、自分の書き方の癖で書く）／本文の固有の言い回し／他人の実績の数字／お客様の声・受講生の例／商品名・肩書き・商標／その人だけの決まり文句

## Step 4: ②を埋める

②の欄の例: `②-1 判断が変わった出来事`、`②-2 数字の実績（根拠のあるもの）`、`②-3 自分の商品と価格`、`②-4 よく聞かれる質問`、`②-5 自分の導線（プロフ・LINE・LP）`。素材の `わたし.md` から探し、無い欄だけを1回で聞きます。

## Step 6: 書く

- 型のパーツ表（売れている理由）と①を見ながら、パーツの順番どおりに書きます。パーツごとに、その理由が自分の文でも働いているかを確かめながら書きます
- 論点は真似し、例・根拠・数字・体験は②だけで書きます。元の例・数字・体験を使いません
- 文の長さ・語尾・一人称は、`素材/わたし.md` の「書き方の癖」で書きます。元の1文の字数に合わせません
- 「AI が書いた感じ」を出さない: 同じ語尾を3回続けない／「いかがでしたか」「〜ではないでしょうか」「さあ、始めましょう」を使わない／読点で言葉を並べて言い切った風にしない／根拠の無い「必ず」「誰でも」を使わない

## Step 7: 比べる

```bash
python3 scripts/text_stats.py --compare 元.txt 完成したもの.txt --allow "自分の商品名,よく使う一般語"
```

- パーツごとに、元のパーツと作ったパーツを並べ、売れている理由が同じ働きをしているか、話の順番・論点・箇条や手順の数（情報量）がそろっているかを見ます。外れているパーツは型の①を直します
- 「元と同じ8文字以上の並び」が1つでもあれば、その所を自分の言葉で書き直します（終わりの状態が 0 か所）
- 長いもの（記事・LP・教材）は、the-copy の `references/judge.md` の「長いものの3層の比べ方」も当てます
- 判定の結果（真似しすぎ・真似できていない）をダッシュボードのメーターに入れます
