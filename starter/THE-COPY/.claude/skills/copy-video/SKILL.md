# THE・COPY 動画（v2v）

全体の流れ（0〜7段）・コピー盤・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには動画の部品だけを書きます。

## どこまでできるか

| 環境 | できること |
|---|---|
| チャット（claude.ai） | 使う人が渡す「場面の画面写真」と「書き起こし（YouTube の文字起こしでもよい）」から、分析・台本・カット表・テロップ表まで。動画ファイルはチャットに上げられないことが多いので、画面写真で見ます |
| 作業フォルダ（Code タブ・Claude Code） | 上に加えて、ffmpeg でカット・無音・音量を測り、手元の CPU で書き起こし、カット表から動画を書き出す |

**守ること**: 他人の YouTube の動画をダウンロードしません（YouTube の規約で禁じられています）。見てよいのは、自分に権利のある動画、YouTube が出す文字起こし、使う人が自分で撮った場面の画面写真です。TikTok・インスタも、使う人が画面写真と書き起こしを渡します。

## Step 1: 全部の場面と全文を見る

作業フォルダで、動画のファイルがある時（自分の動画・権利のある動画）:

```bash
python3 scripts/video_measure.py 素材棚/元の物/<動画> --out 素材棚/元の物/<名前>-measure
python3 scripts/transcribe.py 素材棚/元の物/<動画> --out 素材棚/元の物/<名前>-measure   # 書き起こし（任意）
```

- `summary.md` に、長さ・カットの数・無音・音量などが出ます。`frames/` のカットごとの1枚を全部見て、場面の種類と順を拾います。秒数の値は型に写しません
- 書き起こしから、**元の動画が話したことを箇条書きにします**（段ごとに1行）。これが台本の元になります
- ffmpeg が無い時は、Claude に入れてもらいます（Windows は `winget install Gyan.FFmpeg`、Mac は `brew install ffmpeg`。5〜10分）
- 10分を超える動画は、10分ずつに分けて測ります（メモリを使いすぎないため）

チャットの時: 使う人に「冒頭の3秒・途中の何か所か・最後」の画面写真と、全文の書き起こしをもらい、場面ごとに表にし、話したことを箇条書きにします。見られない場面は「未確認」と書きます。

## Step 2〜3: 売れている理由と①写す物

| 部品 | 変換 | ①に書く物 |
|---|---|---|
| つかみ（最初の場面） | v2v | 最初に見せる物と最初に言うこと（何を約束しているか）、画面の動きの種類（寄る・切り替わる・文字が出る） |
| 台本 | t2t | 元の動画が話したことの箇条書き（段ごとに論点を1行）と、問題 → 反転 → 本題 → 締め のような順番。手順・事例・数字の数 |
| 見せ方 | v2v | 場面の種類の順（顔・手元・画面・文字だけ）と、1場面で言うことの数 |
| テロップ | v2v | テロップの役割（話を全部出す・要点だけ・強調だけ）と、強調する言葉の選び方 |
| 音 | v2v | BGM と無音を、どこで何のために使っているか |
| サムネ・表紙 | i2i | copy-image の①と同じ |

部品ごとに、売れている理由を1行書きます（例: 最初の場面で完成形を見せるので、最後まで見る理由ができる）。

**写さない物**: テロップの大きさ・位置、カットの秒数の値、話す速さの値、元の話の言い回しと決め台詞、元の映像と BGM。

②の欄の例: `②-1 撮る物（顔・手元・画面）`、`②-2 話す体験と手順（自分の物）`、`②-3 BGM（使ってよい物）`、`②-4 話す人の声`。

## Step 6: 作る

1. 台本（t2t）を、元の動画が話したことの箇条書きから作ります。箇条の順と数（論点・手順・事例）をそろえ、1行ずつ自分の体験と手順に置き替えてから、copy-text のやり方で文にします
2. 秒数とテロップの大きさは、自分の動画の見やすさで決めます（縦の動画ならテロップは1行12字前後まで・画面の下から20%前後。読み終わるまで出しておく）
3. カット表を作ります（カットの番号・秒数・映す物・テロップ・音）。CapCut などで編集する人には、この表とテロップ表と BGM の指示を渡して終わりにします（いちばん早い方法です）
4. 作業フォルダで自動で書き出す時は、カット表を JSON にして書き出します

```bash
python3 scripts/render_short.py できた物/<名前>/cuts.json --out できた物/<名前>/short.mp4
```

   形は `scripts/render_short.py` の先頭にあります。テロップの中で強調する所は `[[ここ]]` で囲みます。画像の明るさがカットごとに違う時は、`telop.box` で文字の下に箱を敷きます。素材は自分の写真・画面写真・自分で撮った動画だけを使います。BGM は使ってよい物だけにします
5. 書き出した動画も `video_measure.py` で場面を切り出し、元の場面と並べます

## Step 7: 比べる

| 比べる物 | 元 | 作った物 | 合っているか |
|---|---|---|---|
| 部品ごとの売れている理由が働いているか | | | |
| 最初の場面で見せる物と言うこと | | | |
| 話したことの箇条と順番（台本の段の対応） | | | |
| 手順・事例・数字の数 | | | |
| 見せ方（場面の種類の順・1場面で言うことの数） | | | |

- 写しすぎ: 元の話の言い回し・事例・決め台詞・映像・BGM をそのまま使っていないか
- 写せていない: 最初の場面で約束が無い、1場面で言うことが元より多くてテンポが落ちている、箇条の論点が抜けている、CTA の前の押しが無い
