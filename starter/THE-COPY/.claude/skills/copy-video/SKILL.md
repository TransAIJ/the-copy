# THE・COPY 動画（v2v）

全体の流れ（0〜7段）・コピー盤・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには動画の部品だけを書きます。

## どこまでできるか

| 環境 | できること |
|---|---|
| チャット（claude.ai） | 使う人が渡す「場面の画面写真」と「書き起こし（YouTube の文字起こしでもよい）」から、分析・台本・カット表・テロップ表まで。動画ファイルはチャットに上げられないことが多いので、画面写真で見ます |
| 作業フォルダ（Code タブ・Claude Code） | 上に加えて、ffmpeg でカット・無音・音量を測り、手元の CPU で書き起こし、カット表から動画を書き出す |

**守ること**: 他人の YouTube の動画をダウンロードしません（YouTube の規約で禁じられています）。見てよいのは、自分に権利のある動画、YouTube が出す文字起こし、使う人が自分で撮った場面の画面写真です。TikTok・インスタも、使う人が画面写真と書き起こしを渡します。

## Step 1: 全部の場面と全文を見る

作業フォルダで、動画のファイルがある時（自分の動画・権利のある動画）:

```bash
python3 scripts/video_measure.py 素材棚/元の物/<動画> --out 素材棚/元の物/<名前>-measure
python3 scripts/transcribe.py 素材棚/元の物/<動画> --out 素材棚/元の物/<名前>-measure   # 書き起こし（任意）
```

- `summary.md` に、長さ・カットの数・カットの平均秒数・最初のカットの秒数・無音・音量（LUFS）が出ます。`frames/` のカットごとの1枚を全部見ます
- ffmpeg が無い時は、Claude に入れてもらいます（Windows は `winget install Gyan.FFmpeg`、Mac は `brew install ffmpeg`。5〜10分）
- 10分を超える動画は、10分ずつに分けて測ります（メモリを使いすぎないため）

チャットの時: 使う人に「冒頭の3秒・途中の何か所か・最後」の画面写真と、全文の書き起こしをもらい、カットごとに表にします。測れない値（正確な秒数・音量）は「未確認」と書きます。

## Step 2〜3: 部品と①の値

| 部品 | 変換 | ①に書く値 |
|---|---|---|
| つかみ（最初の1〜3秒） | v2v | 最初のカットの秒数、最初に出る言葉の字数、画面の動き（寄る・切り替わる・文字が出る） |
| 台本 | t2t | 問題 → 反転 → 中身 → 締め の順と、各段の秒数と字数。話す速さ（1秒あたりの字数） |
| カット割り | v2v | カットの平均秒数と幅、カットの種類の順（顔・手元・画面・文字だけ） |
| テロップ | v2v | 1枚の字数、行数、位置（下から何%）、大きさ、縁取り、強調の色の数 |
| 間と音 | v2v | 無音の長さ（何秒以上を詰めるか）、BGM の音量の比、音量（LUFS） |
| サムネ・表紙 | i2i | copy-image の値 |

②の欄の例: `②-1 撮る物（顔・手元・画面）`、`②-2 話す中身（自分の体験と手順）`、`②-3 BGM（使ってよい物）`、`②-4 話す人の声`。

## Step 6: 作る

1. 台本（t2t）を copy-text のやり方で書きます。秒数は①の「1秒あたりの字数」で割って合わせます
2. カット表を作ります（カットの番号・秒数・映す物・テロップ・音）。CapCut などで編集する人には、この表とテロップ表と BGM の指示を渡して終わりにします（いちばん早い方法です）
3. 作業フォルダで自動で書き出す時は、カット表を JSON にして書き出します

```bash
python3 scripts/render_short.py できた物/<名前>/cuts.json --out できた物/<名前>/short.mp4
```

   形は `scripts/render_short.py` の先頭にあります。素材は自分の写真・画面写真・自分で撮った動画だけを使います。BGM は使ってよい物だけにします
4. 書き出した動画も `video_measure.py` で測り、元の値と並べます

## Step 7: 比べる

| 比べる値 | 元 | 作った物 | 合っているか |
|---|---|---|---|
| 長さ・カットの数・カットの平均秒数・最初のカットの秒数 | | | |
| テロップの字数・位置・大きさ | | | |
| 無音の合計・音量（LUFS） | | | |
| 台本の順番と各段の秒数 | | | |

- 写しすぎ: 元の話の中身・決め台詞・映像・BGM をそのまま使っていないか
- 写せていない: 冒頭のつかみが遅い（元より長い）、カットが元より長くてテンポが落ちている、CTA の前の押しが無い
