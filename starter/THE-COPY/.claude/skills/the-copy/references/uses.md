## 型の短い名前（3段目）の付け方

目的か読み手で ①形式 か ②の在りか が変わる単位で分けます。例: `howto`（手順を教える）、`story`（体験談）、`list`（〇〇選）、`consult`（相談に誘う）、`launch`（新しい物を知らせる）、`tips`（小ネタ）。

## 用途ごとの注意

- X の投稿は、使う人が本文を貼るか、スクショを渡します。THE・COPY は X を開きに行きません
- YouTube の動画は、自分に権利がある物か、YouTube が出す文字起こしと、使う人が撮った場面の画面写真から見ます。他人の動画をダウンロードしません
- LP・スライド・アプリの画面は、元の画像・文章・ロゴ・イラストを使わず、書体・大きさ・太さ・行間・余白・列の幅・区画の順番を値で写します
- 写真の i2i は、Claude が写真を作れないため、別の画像のモデルを使います（copy-image の「写真の作り方」）
