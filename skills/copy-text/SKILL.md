# THE・COPY 文章（t2t）

全体の流れ（0〜7段）・コピー盤・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには文章の部品だけを書きます。

## Step 1: 全文を1文ずつ見る

- 元の本文を `素材棚/元の物/<名前>.txt` に保存します（チャットでは会話の中に置きます）。X の投稿は、使う人が本文を貼るかスクショを渡します。取りに行きません
- 前後の文脈も見ます: 投稿なら前後の投稿・プロフィール・添付画像の有無、記事なら題名と見出しの並び、メールなら件名
- `python3 scripts/text_stats.py <元.txt>` で数えます。Python が無い時は、同じ項目を Claude が数えます

## Step 2〜3: 部品と①の値

用途ごとの部品の雛形は the-copy の `references/uses.md` にあります。文章では次の項目を必ず見て、①の値にします。

| 見る項目 | ①に書く値の例 |
|---|---|
| 冒頭 | 1文目の字数、入り方（場面・数字・言い切り・問いかけ・会話文）、2文目で何をするか |
| 読み手 | 誰に向けているか（はじめての人・比べている人・もう使っている人） |
| 痛み | 表の悩みと本音を分けて1行ずつ |
| 欲求 | 売上・承認・楽さ・安心・優越感のどれを刺しているか |
| 証拠 | 実績・数字・具体の場面・失敗・比べ・スクショの、どれを何個どこに置くか |
| 展開 | 問題 → 原因 → 反転 → 解決 → 行動 の順番と、各段の文の数 |
| CTA | どこで・どの強さで・何をさせるか。CTA の前の押しの1文 |
| 文体 | 文の長さの平均と幅、改行の数、語尾の割合、箇条の数、かぎ括弧の数 |

借りてよい物: 冒頭の入り方／読み手を自分のことだと思わせるやり方／具体例の置き方／反論への答えの順番／CTA の前の押し方／区画の順番／証拠の出し方

借りない物: 本文の固有の言い回し／他人の実績の数字／お客様の声・受講生の例／商品名・肩書き・商標／その人だけの決まり文句

## Step 4: ②を埋める

②の欄の例: `②-1 判断が変わった出来事`、`②-2 数字の実績（根拠のある物）`、`②-3 自分の商品と価格`、`②-4 よく聞かれる質問`、`②-5 自分の導線（プロフ・LINE・LP）`。素材棚の `わたし.md` から探し、無い欄だけを1回で聞きます。

## Step 6: 書く

- 型の①の値と、元の原文を両方見ながら、部品の順番どおりに書きます
- 中身は②だけで書きます。元の例・数字・体験を使いません
- 「AI が書いた感じ」を出さない: 同じ語尾を3回続けない／「いかがでしたか」「〜ではないでしょうか」「さあ、始めましょう」を使わない／読点で言葉を並べて言い切った風にしない／根拠の無い「必ず」「誰でも」を使わない

## Step 7: 比べる

```bash
python3 scripts/text_stats.py --compare 元.txt できた物.txt --allow "自分の商品名,よく使う一般語"
```

- 表で①の値（字数・段落・語尾・箇条）が元に近いかを見ます。外れている項目は型の①を直します
- 「元と同じ8文字以上の並び」が1つでもあれば、その所を自分の言葉で書き直します（終わりの状態が 0 か所）
- 長い物（記事・LP・教材）は、the-copy の `references/judge.md` の「長い物の3層の比べ方」も当てます
- 判定の結果（写しすぎ・写せていない）をコピー盤のメーターに入れます
