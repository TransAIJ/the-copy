# THE・COPY 画像と画面（i2i）

全体の流れ（0〜7段）・コピー盤・判定は the-copy スキルが持っています。まだ読んでいなければ、先に the-copy スキルを読みます。ここには画像と画面の部品だけを書きます。

i2i は2種類に分けます。

| 種類 | 例 | 作り方 |
|---|---|---|
| 配置（文字と枠が主役） | LP・スライド・アプリの画面・文字の多いインスタの画像・図解・バナー | HTML と CSS で作り、同じ幅で撮る（Claude だけでできる） |
| 写真の層（絵が主役） | 写真・イラスト・サムネの人物や背景 | 画像のモデルが要る（下の「写真の作り方」） |

1つの画像に両方がある時（写真の上に文字が乗ったサムネなど）は、部品を「写真の層 i2i」と「文字の層 i2i」に分け、文字は HTML で重ねます。画像のモデルに日本語の文字を書かせると崩れるためです。

## Step 1: 見る

### 配置（LP・画面・文字の画像）

- スマホ 390px とパソコン 1440px の両方で、上から下まで区画ごとに見ます
- 作業フォルダで Node.js がある時は、台本で区画ごとの画面写真と、見出し・本文・ボタンの並びを取ります。区画の順と、区画ごとの情報の数を拾うためです

```bash
npx -y playwright@1 install chromium   # 初回だけ（数分）
node scripts/measure_page.mjs <URL> --out 素材棚/元の物/<名前>
```

  1画面ずつの画面写真（`sp-01.png`…・`pc-01.png`…）と、見出し・本文・ボタンの並びと値を `measure.json` に書きます。文字の大きさや余白の値も入りますが、型には写しません
- 台本を使えない時（チャット・Node.js が無い）は、使う人からスマホとパソコンの画面写真をもらい、Claude が画像を見て区画を拾います
- ログインの要るページは開きに行きません。使う人の画面写真で見ます

### 写真・イラスト

要素ごとに次の10項目を書きます: ①写っている範囲（全身・上半身・手元）②顔の出し方 ③姿勢 ④カメラの距離と角度 ⑤主役（顔・手元・商品・小物）⑥見た人の気持ちを動かす芯 ⑦小物 ⑧服 ⑨背景 ⑩AI っぽく崩れやすい所（手指・目・文字）

## Step 2〜3: 売れている理由と①写す物

| 部品 | ①に書く物 |
|---|---|
| 売れている理由 | 区画ごと・1枚ごとに1行。読み手が何をするかで書く（例: 実物の画面を先に見せるので、何が手に入るか1秒で分かる） |
| 区画の順と役割 | ファーストビュー → 問題 → … → CTA。各区画が読み手に何をさせるか |
| 見せ方 | 比べて見せる・実物を先に見せる・数字を大きく見せる・手順を番号で見せる・一覧で量を見せる など |
| 中身 | 区画ごとに扱っている話題と論点 |
| 情報量 | 区画・1枚ごとの見出し・箇条・証拠・画像の数、FAQ の数 |
| CTA | ボタンの数と位置、CTA の前に置く押し（証拠・期限・特典） |
| 色 | 色の役（地・本文・強調の3つ）の使い分け。色そのものは自分のブランドの色に替える |
| 写真 | 上の10項目のうち、主役・気持ちを動かす芯・写っている範囲・カメラの距離と角度 |

**写さない物**: 寸法（文字の px・太さの値・行間・字間・余白・列の幅）と、元の画像・文章・ロゴ・イラスト・人物・商標。

## Step 6: 作る

### 配置（HTML で作って撮る）

1. 区画の順と役割・見せ方・情報の数を①どおりに組みます。部品ごとの売れている理由が、自分の区画でも働くようにします
2. 寸法は元から取りません。`素材棚/わたし.md` の「見た目の決まり」があればそれで、無ければ読みやすさの既定で決めます（スマホ 390px で本文 16px 以上・注記 13px 以上・行間 1.7 前後・ボタンの高さ 48px 以上。書体は2つまで）
3. ②（自分の文章・自分の写真・自分の実績）で埋めます。画像が無い所は、灰色の枠に「（ここに〇〇の写真）」と書いて残します
4. スマホ 390px とパソコン 1440px で撮り、元の画面写真と区画ごとに横に並べます
5. インスタの画像やバナーのように1枚の画像にする物は、その縦横比の HTML（例: 1080×1350）を作って撮ります

### 写真の作り方（使う人が選ぶ。既定は「手で貼る」）

詳しくは `references/photo-routes.md` です。

| 方法 | 使う人の手間と費用 |
|---|---|
| 1. 手で貼る（既定） | THE・COPY が「元の画像」と「写す所・替える所を書いた短い指示」を出し、使う人が ChatGPT か Gemini のアプリに元の画像と一緒に貼る。導入は0分 |
| 2. Codex で自動（作業フォルダ） | 使う人の ChatGPT のログインで動く Codex の画像生成を呼ぶ。Codex の導入とログインが要る |
| 3. 使う人の API キー（作業フォルダ） | `scripts/image_api.py` で OpenAI か Gemini の画像の API を呼ぶ。1枚ごとに使う人が払う。キーが無ければ動かない |

守ること: 元の写真の人物・顔・ロゴ・文字を出力に残さない。実在の人に見える画像を作らない。モデルの安全判定で止められた物を言い換えて通さない。

## Step 7: 比べる

- 元と作った物を、同じ幅・同じ区画で横に並べた画像を作ります（作業フォルダでは `できた物/<名前>/compare.png`）。並べた画像に付ける見出しの文字は、HTML に2枚を並べて撮って入れます。Python の画像の部品（PIL）の既定の書体では、日本語が四角になります
- 区画ごとに、元の区画と作った区画の売れている理由・役割・見せ方・情報の数が対応しているかを表にします。寸法が元と違うのは正しい状態です
- 写しすぎ: 元の画像・文章・ロゴが残っていないか。構図だけでなく服・小物・背景まで同じになっていないか
- 写せていない: 区画の順だけ似て、売れている理由（証拠・反論への答え・押し）が自分の区画に入っていないか
