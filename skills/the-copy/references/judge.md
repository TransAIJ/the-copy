# 何を真似し、何を真似しないか（判定）

THE・COPY の目的は、お手本が売れている理由（勝ち筋）を自分の文脈に移すことです。言い回しや絵や寸法を真似することではありません。

## 層ごとの扱い

| 層 | 中身 | 扱い |
|---|---|---|
| 理由 | 誰の・どの欲求を・何で動かしているか（パーツごとに1行） | 必ず書いて真似します。全体で1行、パーツごとに1行ずつ |
| 構造 | 話の順番・区画の順と各区画の役割・見せ方（比べて見せる・実物を先に見せる・1場面に1つ など）・CTA の位置・画角と主役 | 真似します。順番と役割で書きます |
| 中身 | 扱っている話題と論点 | 真似します。論点は真似し、例・根拠・数字は自分のものにします |
| 情報量 | 項目・事例・手順・証拠・FAQ の数 | 真似します。数で書きます |
| 寸法 | 文字の px・太さ・行間・字間・余白・列の幅・1文の字数・カットの秒数 | 真似しません。自分のブランドの決まりと読みやすさで決めます |
| 表面 | 文言・言い回し・決め台詞・写真・固有名詞・ロゴ・イラスト | そのまま使いません |
| 文脈 | 誰が言うか・どの商品か・実績・体験・写真・声 | ②一次情報です。自分のもので作り直します |

心理（欲求・不安・憧れ・反論）は、売れている理由の1行を書くために必ず読みます。元が何を刺しているかを1文で言えるまで読みます。

色は、色の役（地・本文・強調の3つ）を構造として真似し、色そのものは自分のブランドの色に替えるのを既定にします。

## 浅い真似の仕方と深い真似の仕方

浅い真似の仕方（失敗しやすい）: 口調だけ似せる／色や書体だけ寄せる／文字の大きさや余白の値だけ合わせる／似た構図だけ作る／本文を言い換える

深い真似の仕方: 誰のどの欲求を刺しているかを見る／冒頭で指を止める仕掛けを見る／信用・証拠・欲望・行動の順番を見る／読み手が動く理由を抜き出す／自分のブランドと規約に合わせて変える

## 真似しすぎ（2つ以上残ったら出さない）

- 固有の言い回しがほぼ同じ
- 段落の順と文意が同じ
- 画像の構図だけでなく、衣装・小物・背景まで同じ
- 実績の数字や事例が同じ
- CTA の文言まで同じ
- 読み手が見てお手本を思い出せる

直し方: 例の分野を替える／読み手の痛みを自分の読み手のものにする／証拠を自分の材料に替える／CTA の文言を自分の導線に合わせて作り直す

文章は `copy-text/scripts/text_stats.py --compare <元> <作ったもの>` で、元と同じ8文字以上の並びを数えます。1つでもあれば、その所を書き直します（固有名詞や一般的な言い方「Claude Code」「無料で」などは除いてよい）。

## 真似できていない（2つ以上あったら型を直す）

- 冒頭の強さが消えている
- 読み手の欲求が変わっている
- 区画の順や寸法だけ似ていて、売れている理由（証拠・反論への答え・押し）が入っていない
- 画像の種類だけ似ていて、画角・距離・主役が違う
- 口調だけ寄せて、CTA の前の押しが無い
- 元の勝ち筋を説明できない

直し方: お手本に戻って、パーツごとの売れている理由と①を書き直す／「なぜ伸びたか」「なぜ欲しくなるか」を先に1文で決める／作ったもののパーツごとに、対応する元のパーツを並べる

## 長いものの3層の比べ方

記事・教材・LP のように章が続くものは、文字の一致だけで判定しません。次の3つを別々に比べます。

1. 表面の言葉: 固有の表現・たとえ・数字・文の一致
2. 区画の役割: 各章・各区画が読み手に何をさせるか
3. 読み手の動く順番: どの問題から入り、何を分かり、何を試し、何をゴールにするか

表面が違っても2と3が大半同じなら、全体は元の言い換えに見えます。これは②（自分の主張と事例）が入っていない時に起きます。自分の中心の主張を1行で決め、そこから章と順番と例を作り直します。

## ダッシュボードのメーター

ステップ7で、判定した当たりの数を、そのまま job.json の meter に入れます。本文で使う人に伝える数と同じ数にします（メーターの数を別に見積もりません）。

```json
"meter": { "over_items": 0, "under_items": 0, "same8": 0 }
```

- over_items: 真似しすぎの6項目のうち当たった数（0〜6）
- under_items: 真似できていないの6項目のうち当たった数（0〜6）
- same8: お手本と同じ8文字以上の並びの数（`text_stats.py --compare` の結果。文章でない時は 0）

ダッシュボードは数字を「◯項目」で出し、棒の長さを次の数え方で出します。真似しすぎ = over_items × 15 ＋ same8 × 5、真似できていない = under_items × 15（どちらも100で止める）。2項目以上か、同じ並びが1つでもあれば、棒が強調の色になります。

## 出す前の確かめ

| 決まり | 見るもの |
|---|---|
| 著作権 | 元の文章・画像・ロゴ・イラストがそのまま残っていないか。i2i で作った画像が元と似すぎていないか（文化庁「AIと著作権に関する考え方について」2024年3月: 作風はアイデアとして保護されないが、元の作品を入力して作ったものは依拠性が認められやすく、表現が似れば侵害になり得る） |
| 景品表示法 | 「No.1」「必ず」「誰でも」「〇日で〇万円」など根拠の無い言い切りと数字。お客様の声の作り話 |
| 肖像権・パブリシティ権 | 実在の人の顔・名前・声を使っていないか |
| 各サービスの規約 | 自動での取得・投稿、同じ文の繰り返し投稿。YouTube は他人の動画をダウンロードすることを規約で禁じています |
| ブランド | 露骨に真似した印象・下品さで、自分の信用を下げていないか |
