## 最初の1本（同梱の手本ですぐ試す）

最初の1本は、次の1文で頼めます。

> THE・COPYで、同梱の手本の作り方で、私の商品のX投稿を1本作って

この頼み方の時と、元の物を渡されずに「試したい」「何か作って」と頼まれた時は、下の短い流れで作ります。下の「流れ」の Step 1〜3 は、同梱の手本では済ませてあります。

1. このスキルのフォルダにある `examples/x-moto.txt`（手本の X 投稿）と `examples/x-moto-kata.md`（手本を部品に分け、部品ごとの売れている理由・①写す物・②の欄を書いた物）を読みます
2. 作業フォルダの `素材棚/わたし.md` か `わたし.md` を探します。無い時は、**次の3つだけを1回のメッセージで聞いて、答えを待ちます**。選ぶ形にせず、自由に書いて答えられる形で聞きます。ほかの事は聞きません
   1. 商品: 何を売っていますか（名前・中身・価格。申込先や受け取り方の URL があればそれも）
   2. 誰に売るか: 誰に向けた商品ですか。その人がよくつまずく所を2〜3個
   3. 実績: 言ってよい数字や経験を1〜3個（根拠も一言）。無ければ「無し」
3. 答えを作業フォルダの `素材棚/わたし.md` に書いて残し（`素材棚/` が無ければ作ります）、次からは聞きません。チャットではフォルダが無いので、答えをこの会話の②として使い、最後に `わたし.md` の形で渡します
4. `examples/x-moto-kata.md` の部品の順番で、部品ごとの売れている理由が働くように、自分の素材で1本書きます。答えに無い数字・実績・お客様の声・体験は作らず、足りない所は「（ここに〇〇）」と残します
5. 手本と同じ8文字以上の並びが無いかを `scripts/text_stats.py --compare` で数え、`references/judge.md` で写しすぎ・写せていないを判定します
6. 作った物を `できた物/<日付>-xpost/post.md` に置き（チャットではそのまま見せ）、本文と、手本から写した事・写さなかった事を短く渡します。最後に「この作り方を自分の型として保存しますか」とはい・いいえで聞きます。はいなら Step 5 の形で型を残します

Claude Code やデスクトップアプリの Code タブ（フォルダを開いて使っている時）では、コピー盤も出します（下の「コピー盤」）。最初の1本では、次の4回だけ盤を書きます。
- 手本を読んだ後、3つを聞く前: `--init --serve 8765` を裏で動かし、`examples/x-moto-board.json` を job にして 1・2・3 段を2秒ずつ空けて順に書きます（1〜3段は手本の分解を読む段です）。使う人に「http://localhost:8765/ を開くと、コピーしている様子が見られます」と1行で伝えます
- 答えを `わたし.md` に書く時: 4段（parts の filled に、埋めた中身を短く入れる）
- 書き始める時: 5段（手本の分解を型として使う）と、続けて6段
- 比べる時: 7段（meter に写しすぎと写せていないの度合い（0〜100。`references/judge.md` の数え方）、output に作った物の名前）

台本（`scripts/`）・手順（`references/`）・手本（`examples/`）は、このスキルのフォルダ（この SKILL.md のある所）にあります。作業フォルダから動かす時は、フォルダの場所を付けて動かします（例: `python3 <このスキルのフォルダ>/scripts/board.py`）。
