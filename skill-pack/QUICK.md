## 最初の1本（同梱のお手本ですぐ試す）

最初の1本は、次の1文で頼めます。

> THE・COPYで、同梱のお手本を真似して、私の商品のX投稿を1本作って

この頼み方の時と、お手本を渡されずに「試したい」「何か作って」と頼まれた時は、下の短い流れで作ります。下の「流れ」の Step 1〜3 は、同梱のお手本では済ませてあります。

1. 作業フォルダ（Claude Code・Code タブ）で使っている時は、ほかの何より先に、作業フォルダで `python3 <このスキルのフォルダ>/scripts/rename_folders.py` を1回動かします。0.2 で作ったフォルダがあれば新しい名前（`素材/`・`素材/お手本/`・`完成/`）に移し、CLAUDE.md や自分の型に書かれたフォルダの名前も直します（`わたし.md` と自分の型は消えません）。移すものが無ければ何もしません。フォルダの名前は、この SKILL.md の名前（`素材/`・`完成/`）を正とします
2. このスキルのフォルダにある `examples/x-moto.txt`（お手本の X 投稿）と `examples/x-moto-kata.md`（お手本をパーツに分け、パーツごとの売れている理由・①真似するもの・②の欄を書いたもの）を読みます
3. 作業フォルダの `素材/わたし.md` か `わたし.md` を探します。無い時は、**次の3つだけを1回のメッセージで聞いて、答えを待ちます**。選ぶ形にせず、自由に書いて答えられる形で聞きます。ほかの事は聞きません
   1. 商品: 何を売っていますか（名前・中身・価格。申込先や受け取り方の URL があればそれも）
   2. 誰に売るか: 誰に向けた商品ですか。その人がよくつまずく所を2〜3個
   3. 実績: 言ってよい数字や経験を1〜3個（根拠も一言）。無ければ「無し」
4. 答えを作業フォルダの `素材/わたし.md` に書いて残し（`素材/` が無ければ作ります）、次からは聞きません。チャットではフォルダが無いので、答えをこの会話の②として使い、最後に `わたし.md` の形で渡します
5. `examples/x-moto-kata.md` のパーツの順番で、パーツごとの売れている理由が働くように、自分の素材で1本書きます。答えに無い数字・実績・お客様の声・体験は作らず、足りない所は「（ここに〇〇）」と残します
6. お手本と同じ8文字以上の並びが無いかを `scripts/text_stats.py --compare` で数え、`references/judge.md` で真似しすぎ・真似できていないを判定します
7. 作ったものを `完成/<日付>-xpost/post.md` に置き（チャットではそのまま見せ）、本文と、お手本から真似したこと・真似しなかったことを短く渡します。最後に「この作り方を自分の型として保存しますか」とはい・いいえで聞きます。はいなら Step 5 の形で型を残します

Claude Code やデスクトップアプリの Code タブ（フォルダを開いて使っている時）では、ダッシュボードも出します（下の「ダッシュボード」）。最初の1本では、次の4回だけダッシュボードを書きます。4回とも欠かさず、この順に書きます（1つでも飛ばすと、使う人には途中が見えません）。4回とも、ダッシュボードを書くだけの Bash にします。`わたし.md` や投稿を書く Bash にまとめると、作っている間ずっとダッシュボードが止まって見えます。
- お手本を読んだ後、3つを聞く前: `--init --serve 8765` を裏で動かし、`examples/x-moto-board.json` を job にして、ステップ1・2・3を2秒ずつ空けて順に書きます（ステップ1〜3はお手本の分解を読むステップです）。使う人に「http://localhost:8765/ を開くと、コピーしている様子が見られます」と1行で伝えます
- 答えを受け取ったら、ほかの事をする前に: ステップ4（parts の filled に、埋めた中身を短く入れる）。`わたし.md` が埋まっていて質問しなかった時も、`わたし.md` を読んだらステップ4を書きます
- 投稿を書き始める前に: ステップ5（お手本の分解を型として使う）と、2秒空けてステップ6。投稿はこの後の手で書きます
- 比べる時: ステップ7（meter に、判定の当たりの数をそのまま `{"over_items": 真似しすぎの当たり, "under_items": 真似できていないの当たり, "same8": 同じ8文字以上の並びの数}` で入れる。本文で伝える数と同じにする。output に作ったものの名前）

台本（`scripts/`）・手順（`references/`）・お手本（`examples/`）は、このスキルのフォルダ（この SKILL.md のある所）にあります。作業フォルダから動かす時は、フォルダの場所を付けて動かします（例: `python3 <このスキルのフォルダ>/scripts/board.py`）。
